# SFX Files Needed

Place these two files in this folder:

## whoosh.mp3
Used at every screen transition (slide effect).
- Duration: ~0.5–0.8 seconds
- Style: clean whoosh / swipe sound

## chime.mp3
Used when the CTA screen appears.
- Duration: ~1–2 seconds
- Style: soft chime / notification ding

## Free sources:
- https://pixabay.com/sound-effects/ — search "whoosh" and "chime"
- https://freesound.org — filter by CC0 license
- https://mixkit.co/free-sound-effects/ — no attribution needed
